Keyboard worksheet builder — install on iPhone/iPad

1. Host this folder on any HTTPS web server (GitHub Pages, Netlify, Cloudflare Pages,
   or your own nginx/Docker). HTTPS is required for offline mode.
2. On the iOS device, open the URL in Safari.
3. Tap Share > Add to Home Screen.
4. Open it once while online; after that it works offline.

Your sheets are stored on the device. Use "Export all sheets" on the home screen
now and then to keep a backup in Files or iCloud Drive.
